## 发布的正文

```
【定制AI小工具 · 第1期：外贸订单助手】
做外贸的朋友应该都有这个体验👇
报价单发出去，客户已读不回；
询盘一多，A 级客户和推广骚扰混在一起；
跟进全靠脑子记，一忙就忘了，回头单子已经被别家拿走了😮‍💨

我是做 AI 开发的，翻了很多外贸同行的吐槽，就动手给中小工厂做了个「AI 订单助手」，视频里是真实系统的手机端操作（数据是演示用的）：

1️⃣ 询盘进来，AI 先分级
A 级（产品、数量、价格都明确）优先报价，推广/群发骚扰自动过滤

2️⃣ WhatsApp / 微信聊天，直接粘贴
AI 自动提取：客户、国家、产品型号、数量、目标价

3️⃣ 点一下，出英文报价单
PDF 报价单 + 报价邮件草稿一起生成

4️⃣ 价格不让 AI 编
单价只从你自己的产品库取，自动套起订量、算总价

5️⃣ 每天告诉你今天该跟谁
按 A/B/C 级排跟进节奏，话术 AI 先写好，业务员看一眼、改一改再发

几个我比较在意的点：
✅ 部署在工厂自己的服务器，客户数据不外流
✅ AI 只负责起草，发不发由业务员决定
✅ 可以接飞书群，每天早上推送待跟进名单

现在还在打磨阶段，想听听做外贸的朋友：
你们最想把哪件事交给 AI？报价、跟进、还是整理询盘？
这个系列先从外贸场景做起，下一期做什么工具，评论区你说了算👇
```
