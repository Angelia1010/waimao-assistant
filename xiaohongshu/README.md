## 系列统一规范

### 标题
- **痛点在前，定位词在后**：`<目标人群的痛点问句>？我做了个AI小工具`
- 例：`外贸报价后已读不回？我做了个AI小工具`（≤20 字）
- 新号没粉丝时，"定制AI小工具 No.X" 这种系列名对陌生人没吸引力，不放标题，放在封面和正文第一行。

### 封面（3:4，1080×1440）
- **「定制AI小工具」必须是全图最大的字**（模板：[ep01/scripts/cover2.py](ep01/scripts/cover2.py)、[ep03/scripts/cover3.py](ep03/scripts/cover3.py)）（首版封面只有痛点、没体现定位，改了一次）。
- 左上角黄色角标：`No.XX · 行业篇`
- 第二层：`第X期 + 工具名`；第三层：痛点问句（黄色）+ 3 条功能 ✓
- 右侧：倾斜的手机截图（真实系统界面）
- 底部按钮：`你的行业也想要一个？👇`
- 右下角小字：`演示数据`
- 模板脚本：[ep01/scripts/cover2.py](ep01/scripts/cover2.py)

### 正文
- 第一行：`【定制AI小工具 · 第X期：工具名】`
- 结构：痛点 3 句 → 我是谁、为什么做 → 功能 1️⃣–5️⃣ → 我在意的点 ✅（数据安全 / 人工确认）→ 提问
- 结尾固定：`这个系列先从外贸场景做起，下一期做什么工具，评论区你说了算👇`
- 话题 10 个：行业词 6 个 + `#AI办公 #AI工具 #AI小工具 #AI应用`，**必须从下拉里选中**（变蓝才算话题）

### 视频（9:16，1080×1920，30fps，约 45 秒）
- 开头 3–4 秒痛点卡片 → 每步一个场景（上方大字标题 + 手机框里真实操作录屏）→ 结尾"AI 起草、人来确认"+ 评论区提问
- 每个画面右下角标 `演示数据 · 非真实客户`
- 配音 + 原创配乐，人声响度 -16 LUFS，音乐自动避让人声
- 从第 2 期起：开头先闪 `定制AI小工具 No.XX`，再接痛点

### 数据记录
- 第 1 期：浏览 9、点赞 1（发布后马上改了封面，推荐受影响）
- 第 2 期：浏览 137、点赞 3、评论 1（选题受众更宽）
- 结论：选“人人都会遇到”的痛点；封面文字一次定好再发，发后少改

### 红线
- 正文、评论、首条私信里不放微信号、手机号、二维码、"加V"
- 不编造客户数量、成交数据；演示数据要标注
- 平台自动关联的活动和本期内容无关时，在编辑页取消关联

## 发布流程清单
1. 系统里准备演示数据 → 跑录屏脚本（手机尺寸 390×720 @2x）
2. 画背景 / 抽关键帧检查 → 合成视频
3. 配音（见下方"配音怎么做"）→ 合成配乐 → 混音
4. 出封面，确认「定制AI小工具」最显眼
5. 创作平台上传视频 → 填标题、正文 → 逐个选话题 → **换封面**（默认第一帧是黑的）
6. 检查：封面评估通过、公开可见、关联活动是否相关、原创声明
7. 发布后 1 小时内回复评论，收集下一期选题

## 制作工具链笔记
- 录屏：Playwright + CDP `Page.startScreencast`（JPEG q92，带时间戳，按真实节奏回放）
- 合成：ffmpeg，每个场景单独编码后 `concat -c copy`；手机屏幕用"挖空前景层"叠在录屏上实现圆角
- 配音：工作环境里没有 TTS、外网受限，用的是**用户本机 Chrome 打开百度翻译，调用其朗读接口**合成每句，按字幕时间轴在浏览器 WebAudio 里拼成一条 WAV 再下载回来。也可以直接把 `voiceover.srt` 导入剪映 → 文本朗读
- 配乐：`music.py` 用 numpy 合成的原创曲（112 BPM，Am–F–C–G），按场景切点安排进鼓 / 停鼓 / 收尾，无版权问题
- 上传：浏览器自动上传文件需要对话处于自动批准模式，否则视频、封面要人手动选文件
- 脚本里的路径是制作时的绝对路径（`/home/claude/video`、`/home/claude/rec`），复用时改成自己的目录；录屏前先用 `scripts/seed_demo.py all` 准备演示数据，并以 `STORAGE=sqlite` 启动服务
