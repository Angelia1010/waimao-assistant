## 内容策略

以介绍工具为主，但：
1. **结果先行**：第一个画面就是「发现 3 处对不上」的核对报告
2. **讲来由**：引用评论区单证员的吐槽（转述，不截别人的图）→「所以我做了个不会累的复核员」
3. **人格化**：叫「单证复核员」而不是「单证核对系统」
4. **具体例子**：数量 1,200 vs 1,020、毛重比净重还小、HS 少一位
5. **主动回应顾虑**：数字靠代码核对不靠 AI 猜、单据在自己服务器上、不接外部大模型也能用
