# 第 2 期规划：客户背调 + 开发信生成器

> 状态：规划中。先看第 1 期评论 2–3 天，评论区有集中需求就优先做那个；没有明确方向就按本方案做。

## 一句话

输入客户官网或公司名 → AI 整理客户画像（做什么、主营产品、可能的采购需求）→ 写一封针对这家客户的英文开发信，不是群发模板。

## 为什么选它

1. **话题最热，能扩大受众**：开发信（怎么写、为什么不回、群发被拉黑）是外贸人在小红书讨论最多的话题之一。第 1 期讲"有询盘之后的跟进"，第 2 期讲"找客户"，能覆盖还没询盘的业务员和老板。
2. **画面好拍**：粘贴官网 → 客户画像 → 个性化开发信，前后对比直观，适合 30–45 秒视频。
3. **能接上第 1 期**：开发信发出、客户回复后，直接进询盘分级和跟进流程，系列工具可以连成一套。

## 功能设计（加到现有系统里）

- 新页面「开发客户」：输入官网 URL / 公司名 / 粘贴官网 About 页文字（服务器不方便抓网页时用粘贴）
- AI 输出客户画像：
  - 公司类型（品牌商 / 批发商 / 零售商 / 工程商）、国家、规模判断
  - 主营品类，与我方产品库的匹配度（引用产品库型号，不编造）
  - 切入点：对方可能关心什么（价格 / 交期 / 认证 / 定制）
- AI 写开发信：
  - 主题行 3 个备选
  - 正文 ≤120 词，第一句必须提到对方公司的具体信息
  - 语气可选：简洁 / 专业 / 热情；语言可选：英 / 西 / 法 / 德
  - 附"不要这样写"的反例提示（群发腔、夸大、附件轰炸）
- 一键「存为潜在客户」：写入客户表，状态"已开发"，进入第 1 期的跟进节奏
- 合规：只用公开信息，不抓取个人隐私，不做群发；发信仍由业务员自己发

## 实现要点

- 复用：`app/llm.py`（OpenAI 兼容 + MockLLM 演示模式）、产品库、客户表、跟进节奏
- 新增：`prompts.PROSPECT_PROFILE`、`prompts.COLD_EMAIL`；`/api/prospects` 接口；前端「开发客户」页
- MockLLM 需要补对应的离线演示输出，保证没配密钥也能录视频
- 演示数据：准备 3 家虚构的海外客户官网文字（德国五金批发 / 美国家装零售 / 中东工程商），统一带 Demo 字样

## 视频分镜草案（约 45 秒）

| 场景 | 画面大字 | 内容 |
|---|---|---|
| 开头 | 定制AI小工具 No.02（闪 0.8 秒）→ 开发信发了 100 封，回复 0 封？ | 痛点卡片 |
| 01 | 粘贴客户官网 | 输入框里贴 About 页 |
| 02 | AI 先帮你背调 | 客户画像卡片逐条出现 |
| 03 | 一封只写给他的开发信 | 开发信生成，第一句高亮"提到对方公司" |
| 04 | 群发模板 vs 定制开发信 | 左右对比 |
| 05 | 客户回了？直接进跟进流程 | 存为潜在客户 → 跳到第 1 期工作台 |
| 结尾 | 下一期做什么，评论区说了算 | 提问 |
